# Системные инструкции для проекта Chronos

## 1. Краткое описание проекта и его цели

**Chronos** — это корпоративное веб-приложение, созданное с использованием фреймворка Jmix. Цель проекта — предоставить платформу для учета времени сотрудников. 

В системе предусмотрено два основных сценария использования для двух типов сотрудников:

1.  **Офисные сотрудники:** Для этой группы сотрудников система будет фиксировать время прихода на работу и ухода с работы, обеспечивая точный учет рабочего времени в офисе.

2.  **Мобильные сотрудники:** Эта категория сотрудников (например, торговые представители или сервисные инженеры) выполняет задачи вне офиса, посещая различные объекты или торговые точки. Для них система позволит отправлять события о посещении каждого объекта, что обеспечит контроль за их передвижением и выполненной работой.

Приложение использует современный технологический стек и следует лучшим практикам разработки корпоративных приложений.

## 2. Ключевые технологии

- **Язык:** Java 17+
- **Фреймворк:** Jmix 2.7.1
- **Бэкенд:** Spring Boot
- **Пользовательский интерфейс:** Jmix Flow UI (на основе Vaadin)
- **База данных:** HSQLDB (для разработки), PostgreSQL (для продакшена — **предположение, пожалуйста, подтвердите или измените**)
- **Инструмент сборки:** Gradle
- **Контейнеризация:** Docker

## 3. Принципы стиля кодирования

- **Java:** Следуйте стандартным соглашениям по стилю кода Java. Используйте современные возможности языка, где это уместно.
- **Именование:**
    - **Классы:** `UpperCamelCase`
    - **Методы и переменные:** `lowerCamelCase`
    - **Константы:** `UPPER_SNAKE_CASE`
    - **Сущности Jmix:** Имена сущностей должны быть осмысленными и отражать их назначение.
    - **Представления Jmix:** Имена представлений должны отражать их функциональность (например, `UserListView`, `TaskDetailView`).
- **Форматирование:** Используйте стандартные настройки форматирования IntelliJ IDEA.

## 4. Важные архитектурные паттерны и местоположения ключевых файлов

Проект следует стандартной архитектуре Jmix, разделяя код по функциональным слоям.

- **Сущности (Entities):**
    - **Расположение:** `src/main/java/ru/kvas/chronos/entity`
    - **Описание:** Классы, представляющие модели данных. Это основные строительные блоки доменной модели приложения.

- **Представления (Views):**
    - **Расположение:** `src/main/java/ru/kvas/chronos/view`
    - **Описание:** Классы, отвечающие за пользовательский интерфейс. Каждое представление обычно соответствует определенному экрану или компоненту пользовательского интерфейса.

- **Безопасность (Security):**
    - **Расположение:** `src/main/java/ru/kvas/chronos/security`
    - **Описание:** Роли, политики доступа и другие конфигурации безопасности.

- **Основной класс приложения:**
    - **Расположение:** `src/main/java/ru/kvas/chronos/ChronosApplication.java`
    - **Описание:** Точка входа в приложение Spring Boot.

- **Файлы конфигурации:**
    - **`build.gradle`:** Определяет зависимости проекта, плагины и задачи сборки.
    - **`src/main/resources/application.properties`:** Основной файл конфигурации для приложения Spring Boot.
    - **`open-shift/*.yaml`:** Конфигурации для развертывания в Kubernetes/OpenShift.

## 5. Структура проекта

- **/src/main/java/ru/kvas/chronos/**: Корневой пакет для исходного кода Java.
  - **entity/**: Классы сущностей JPA.
  - **view/**: Классы представлений (экранов) Flow UI.
  - **security/**: Роли и политики безопасности.
  - **ChronosApplication.java**: Главный класс приложения.
- **/src/main/resources/**: Ресурсы приложения.
  - **application.properties**: Основные настройки Spring Boot.
  - **ru/kvas/chronos/view/**: XML-дескрипторы для представлений (если используются).
  - **menu.xml**: Конфигурация главного меню приложения.
- **/src/main/frontend/**: Файлы фронтенда (например, кастомные стили CSS или компоненты).
- **Dockerfile**: Инструкции для сборки Docker-образа.
- **docker-compose.yaml**: Конфигурация для локального запуска с помощью Docker Compose.
- **open-shift/**: Файлы для развертывания в Kubernetes/OpenShift.
